Nesse repositório, desenvolvemos um sistema de cadastro de pratos, onde o usuário poderá logar em sua conta e cadastrar um prato no sistema.

Para isso, o usuário, ao entrar na página inicial, o usuário poderá ver todos os pratos cadastrados, e também separadamente os seus próprios pratos cadastrados. Com isso, ele poderá cadastrar, editar ou excluir pratos.
